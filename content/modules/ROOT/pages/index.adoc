= Red Hat Offline Knowledge Portal
:navtitle: Overview

The Red Hat Offline Knowledge Portal (RHOKP) is a secure, offline version of
Red Hat's proprietary knowledge content for our products. It is a pocket
library of our award-winning Knowledgebase, product documentation, CVEs,
Errata and more — light enough to run at the edge.

[cols="1,2",options="header"]
|===
|What is inside |What it is for

|Over **160,000** Knowledgebase articles and solutions
|Troubleshooting issues in your disconnected environment. This is the part an
access key unlocks.

|More than **10,000** product documents
|Procedures and configuration guidance, to learn about and use Red Hat
products. Browsable without an access key.
|===

RHOKP is useful anywhere Red Hat products are used and connectivity is
limited, from intentionally disconnected secure sites to planned intervals of
low or no bandwidth. A single small container image, it is easy to install and
use, and compatible with Red Hat OpenShift, Podman, or any OCI-compliant
container runtime.

Search is powered by an **Apache Solr** backend engine, which also drives the
portal's Retrieval-Augmented Generation (RAG) indexing.

Ansible has already installed it on a RHEL workload node here. It is **not
running yet**: the portal needs a pull secret to fetch the image, and an
access key to unlock the encrypted Knowledgebase content and the search
index. Both are yours, not the lab's, so your first task is to supply them.

The access key is optional. Without one the portal runs with a banner telling
you your access is limited: you can still browse product documentation,
product lifecycle pages and the Security Data API, but the Knowledgebase and
search stay locked — so it is worth generating one.
