# ansible/secrets

Generated by `scripts/init-secrets.sh`. Two files land here:

| File | Contents |
| --- | --- |
| `access-key.vault` | The RHOKP `ACCESS_KEY`, AES256-encrypted with Ansible Vault |
| `pull-secret.json.vault` | Your `registry.redhat.io` pull secret, AES256-encrypted |

Both are **safe to commit** — without the vault password they are ciphertext.
The vault password lives in `ansible/.vault-password`, which `.gitignore` blocks.

`.gitignore` is deny-by-default in this directory, so a stray plaintext
`pull-secret.json` dropped here will not be committed by accident.

Inspect or edit a file in place:

```bash
ansible-vault view  ansible/secrets/access-key.vault --vault-password-file ansible/.vault-password
ansible-vault edit  ansible/secrets/access-key.vault --vault-password-file ansible/.vault-password
```

Rotate the vault password (re-encrypts both files):

```bash
scripts/init-secrets.sh --rekey
```
